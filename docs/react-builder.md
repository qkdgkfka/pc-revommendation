# React 화면 구조

`src/main.jsx`가 React 18.3.1을 시작한다. Vite가 소스 모듈을 압축하고 해시 파일명과 gzip 파일을 `dist/`에 생성한다. 개발 화면의 API는 Python 서버로 프록시한다.

직접 사양 선택이 첫 화면이다. `src/screens/ManualScreen.jsx`가 카테고리, 검색·필터, 제품 목록과 견적을 렌더링한다. 추천 화면과 그래픽 상세는 `React.lazy`로 필요할 때 로드한다. 기존 색상, 필터 구조, 카드와 반응형 레이아웃을 유지한다.

## 상태와 요청

`src/state/store.js`가 화면 입력, 부품 선택, 추천 결과와 검색 상태를 관리한다. 화면 전환으로 컴포넌트가 바뀌어도 상태는 유지된다. `src/domain/`의 순수 함수가 제품 규격, 가격 출처, 필터와 호환성을 계산한다. 숨겨진 select 요소나 전역 DOM 이벤트로 상태를 전달하지 않는다.

`src/state/requests.js`는 같은 조건의 진행 중인 요청을 공유한다. 조건 변경과 초기화는 이전 요청을 취소하며, 응답의 요청 버전을 검사하여 늦은 응답을 무시한다. 제품은 판매처 조회가 끝난 후 표시한다. 새 검색을 시작할 때 이전 조건의 목록은 비우며, 더 보기는 기존 페이지 아래에 결과를 추가한다. 한 페이지는 50개이며 서버 커서와 SKU 중복 제거를 유지한다.

취소, 시간 초과, 판매처 오류와 빈 결과를 구분한다. 목록 로딩 영역에는 최소 높이를 지정한다. 동일 부품·게임·해상도의 FPS 계산은 재사용하고, 부품이나 조건이 바뀌면 진행 중인 계산을 취소한다.

## 내 견적과 접근성

- 견적과 예상 성능을 독립 스크롤 영역으로 제공하며 키보드로 진입할 수 있다.
- 제품 이미지, 확인가 출처·시각, 호환성 경고를 공통 함수와 컴포넌트로 표시한다.
- CPU는 제품군과 모델명, 나머지는 유통사·포장 문구를 제거한 이름을 표시한다. 전체 이름은 title에 보존한다.
- 현재 검색 카테고리의 견적 항목은 파란 글자와 연한 배경으로 강조한다.
- 모바일에서는 견적으로 이동하는 하단 버튼을 제공한다.
- 게임 선택은 키보드 조작과 검색을 지원하며 기존 아이콘 URL을 유지한다.

## 검증

순수 계산과 상태 전이는 ES 모듈 기반 Node 테스트로, 서버 계약과 계산은 Python 테스트로 검증한다. 브라우저 검증은 추천·가져오기·필터·검색·페이지네이션·호환성·FPS·그래픽 상세와 화면 전환 및 오류 처리를 확인한다. 실행 방법과 최종 측정 결과는 README와 리팩토링 검증 보고서를 참고한다.
