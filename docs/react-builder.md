# React 직접 사양 선택 UI

`manual_builder.js`가 카테고리, 검색/필터, 제품 목록, 견적을 렌더링하고 `manual_builder.css`가 반응형 스타일을 담당한다. 기존 `app_utils.js`의 선택 상태, 가격 조회, 페이지네이션 및 성능 계산을 재사용한다. 성능 패널은 기존 이벤트 연결을 유지하는 DOM 영역으로 React에 연결한다.

샵다나와의 카테고리 → 조건 → 상품 → 견적 흐름을 참고하고, 기존의 파란 강조색과 밝은 배경, 둥근 카드 스타일을 유지했다. 주요 필터 5개를 먼저 보여주고 상세 항목은 펼칠 수 있다. 실제 판매처 사양과 가격 출처를 표시하며, 없는 사양이나 성능 수치를 만들지 않는다.

## 내 견적

- 견적과 예상 성능을 하나의 독립 스크롤 영역으로 묶었다. 휠 스크롤이 본문으로 이어지지 않으며 키보드로도 영역에 진입할 수 있다.
- 선택한 제품의 동일 이미지 조회 경로를 사용한다. 이미지 조회 실패 시 기존 대체 이미지를 사용한다.
- CPU는 제품군과 모델명, 나머지는 유통사·포장 문구 등을 제거한 이름을 표시한다. 전체 이름은 title에 보존한다.
- 현재 검색 카테고리의 견적 항목은 파란 글자와 연한 배경으로 강조한다.
- 모바일에서는 견적으로 이동하는 하단 버튼과 높이 제한이 있는 견적 스크롤을 제공한다.

## 검증 (2026-09-30)

- Python unittest 158개, Node 테스트 32개 통과.
- 브라우저에서 CPU 및 메인보드 선택, 실제 썸네일 로딩, 이름 축약, 카테고리 변경 강조, 검색창 중복 방지 확인.
- 견적 내부 스크롤로 예상 FPS 영역 접근 및 본문 위치 유지 확인.
- 기존 GPU 시리즈/필터/50개 페이지네이션의 원인 및 구조는 retail-catalog.md 참조.
