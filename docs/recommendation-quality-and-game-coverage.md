# 추천 품질 및 게임 목록 변경 (2026-10-09)

## 부품 추천

- GPU 성능 지수가 최소 15% 및 3포인트 개선돼야 다음 게임 등급으로 인정한다. CPU·RAM 용량·저장 용량·평균 FPS·1% Low가 이전 구성보다 낮아지는 조합은 제외한다.
- CPU 병목이 있는 구성은 CPU 지수 10% 및 3포인트, 해당 게임 평균 FPS 또는 1% Low 15% 및 5fps 개선으로 상위 등급을 구성할 수 있다. GPU가 같은 등급을 반복하는 것보다 GPU 단계가 다른 구성을 먼저 선택한다.
- 작업 등급은 작업 점수가 10% 및 5포인트 이상 개선돼야 한다. 재고·예산으로 차이를 만들 수 없으면 동일한 구성을 복제하지 않는다.
- RAM·SSD는 같은 용량끼리 비교한다. RAM은 DDR 세대도 같아야 한다. 제조사 인지도는 구매 선호이며 신뢰성 인증이나 FPS 배율이 아니다.
- RAM은 명시된 전송 속도와 CL 지연, SSD는 명시된 NVMe·NAND·DRAM·순차 읽기/쓰기 사양을 평가한다. 없는 사양을 추정해 채우지 않는다.
- 동급 최저가 대비 35%를 넘는 추가 비용부터 감점한다. 예산·호환성 검사는 그대로 적용하며, 후보 압축에서도 저렴한 대안을 보존한다.

## FPS 검증

요청한 프리셋 또는 가장 가까운 프리셋의 실측을 우선한다. RAM 용량이 다른 측정치를 한 쌍으로 합치지 않으며, 측정 당시의 메모리 부족 효과를 중복 적용하지 않는다. 원문 RAM 용량이 불명확하면 신뢰도를 낮춘다. 서로 다른 테스트 환경의 옵션별 결과는 직접 비교에 한계가 있음을 표시한다.

기존 스냅샷 407건을 고정한 교차 검증:

| 검증 방식 | 예측 가능 | 게임별 평균 상대 오차: 이전 → 개선 |
|---|---:|---:|
| CPU·GPU·해상도·프리셋이 같은 모든 중복 측정치를 제외 | 404/407 | 11.46% → 10.72% |
| 해당 게임에서 대상 GPU의 모든 측정치를 제외 | 399/407 | 12.29% → 12.29% |

첫 검증의 1% Low 게임별 평균 상대 오차는 14.22% → 13.72%다. 이는 저장된 리뷰 데이터의 검증 결과이며 모든 게임·패치·장면의 오차를 보장하지 않는다. 기존 측정 수치는 변경하지 않았다.

재현: `python3 scripts/validate_fps_accuracy.py --mode condition` 또는 `--mode gpu`.

### FPS 오차 추가 개선

같은 GPU·CPU·리뷰·버전·장면·프리셋·RAM 조건에서 목표 해상도의 양쪽 실측이 있으면, 픽셀 수에 따른 프레임 시간(1/FPS)을 보간한다. 평균 FPS와 1% Low는 각자의 실측으로 계산한다. 역전된 곡선, 다른 테스트 환경, 관측 해상도 범위 밖에는 새 방식을 적용하지 않는다. 실측값과 추정값의 구분 및 기존 대체 경로를 유지한다.

서버가 시작될 때만 설정하던 7개 게임 프로필을 공용 카탈로그로 옮겼다. 검증 도구와 실제 서버의 설정이 이제 동일하다. 아래 비교는 **변경 전에도 실제 서버 프로필을 적용하여 다시 계산한 값**이다. 따라서 앞서 기록한 검증 도구의 10.72%와 기준이 조금 다르다.

| 검증 지표 | 변경 전 | 변경 후 |
|---|---:|---:|
| 조건 제외, 게임별 평균 FPS 상대 오차 | 10.77% | 10.26% |
| 조건 제외, 전체 측정 평균 FPS 상대 오차 | 7.80% | 7.26% |
| 조건 제외, 게임별 1% Low 상대 오차 | 13.72% | 13.30% |
| 조건 제외, 전체 측정 1% Low 상대 오차 | 13.60% | 13.14% |
| GPU 전체 제외, 게임별 평균 FPS 상대 오차 | 12.36% | 12.36% |
| GPU 전체 제외, 게임별 1% Low 상대 오차 | 16.13% | 16.13% |

407건, 조건 제외 예측 가능 404건, GPU 제외 399건으로 분모는 그대로다. GPU 전체를 제외하면 동일 GPU 해상도 곡선이 없어 개선 대상이 아니다. 게임별로는 개선과 악화가 함께 존재한다(예: 스페이스 마린 2 11.26%→8.19%, 더 라스트 오브 어스 1 9.53%→10.68%). 이 데이터로 개선안을 선택했으므로 독립적인 새 리뷰에 대한 성능 보장은 아니다. 미실측 게임의 정확도가 검증됐다는 의미도 아니다.
