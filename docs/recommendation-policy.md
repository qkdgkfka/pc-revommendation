# 추천 정책 리팩토링 (2026-09-26)

## 요청과 적용 기준
- 추천에만 인텔 13세대 이상 제한을 적용합니다. 기존 직접 선택 목록과 FPS 데이터는 유지합니다.
- Core Ultra 200S를 더 최신의 인텔 데스크톱 계열로 우대합니다. 공식 명칭을 임의로 15세대로 표시하지 않습니다.
- 게임에서 AMD에 선호 점수를 줍니다. 목표 FPS를 충족하는 인텔보다 미달하는 AMD를 우선하지 않습니다. 작업 모드에는 AMD 게임 선호 점수를 적용하지 않습니다.
- GPU는 칩셋 성능 등급과 제조사 제품군을 분리합니다. DUAL / VENTUS / GAMING OC / PULSE 등 보급형~중급형 제품군을 선호하고, 최저가만으로 후보를 두 개 남기던 수집 단계에도 제품군 다양성을 보존합니다.
- 제품군 분류는 명시적인 선호 규칙이며, 실제 소음·온도·수명 측정 점수가 아닙니다. 미분류 제품을 가격만으로 상급/하급으로 추측하지 않습니다.
- M.2 NVMe를 우선하고 M.2 SATA와 2.5인치 SATA를 구분합니다. 예산이나 후보 부족으로 SATA가 필요한 경우는 남겨둡니다.

## 구조
`recommendation_policy.py`에 CPU 자격, 세대 선호, GPU 제품군, SSD 인터페이스 선호, 최종 목적 점수를 분리했습니다.
`server_fixed.py`는 이를 수집 후보·탐색 후보·최종 구성 점수에 적용합니다.

1. 실제 가격·사진 확인 및 호환성 검사 유지.
2. 인텔 세대 제한, GPU 칩셋/제조사 선호 필터.
3. 예산 범위 밖 구성 제외. 명시한 budget_max가 다른 budget 값보다 우선.
4. 부품별 최저가의 합부터 예산을 넘으면 조합 탐색을 즉시 종료.
5. 사용자가 선택한 FPS가 세 등급의 공통 목표. 원신·엘든 링 등 게임 자체 제한 유지.
6. 목표 충족에 우선 점수, 이후 성능·가치·예산 및 부품 선호 점수.
7. CPU/GPU/메모리 등의 역전 방지 조건은 유지하면서 목적 점수를 우선한 LOW/MID/HIGH 조합 선택.
8. 실제 업그레이드가 없으면 같은 구성임을 표시. 예산 초과 구성으로 카드를 채우지 않음.

FPS 계산식과 실측값에 제조사별 임의 배수를 곱하지 않습니다.
후보를 제한한 탐색이므로 모든 판매 상품 조합의 수학적 전역 최적해를 보장하는 방식은 아닙니다.
가격과 사진이 검증된 현재 후보, 게임별 FPS 근거의 범위 안에서 추천합니다.

## UI
- GPU 안내 문구: “선택하지 않으면 예산 안에서 보급형~중급형 제품군을 우선 추천합니다”
- DLSS/FG 패널의 “기능 지원 정보” 링크 제거. 실측 자료의 “측정 출처” 링크는 유지.
- 예산에 맞는 후보가 없을 때 예산·선호 조건 조정을 안내.

## 검증
- 실제 100~200만원 / 사이버펑크 2077 / QHD 60FPS: LOW 1,001,360원, MID 1,594,220원, HIGH 1,996,320원. AMD CPU, GAMING OC/DUAL GPU, M.2 NVMe 선택.
- 실제 150~300만원 / CS2 / FHD 144FPS: Ryzen 9900X 또는 9800X3D, DUAL/WINDFORCE GPU, M.2 NVMe 선택.
- 30만원으로 구성이 불가능할 때 초과 견적 없이 응답: 약 0.81초.
- 실제 판매가 및 결과 상세: `artifacts/recommendation-policy-live.json`.
- 예전 테스트 중 “30만원에서도 초과 견적 표시”, “등급별 목표 FPS를 다르게 설정”, “목표 점수보다 업그레이드 우선” 기대값은 새 정책에 맞게 변경했습니다.
- 인텔 구형 차단, 최신 인텔 유지, 게임 전용 AMD 우선, 목표 충족 우선, GPU 제품군, M.2/SATA 구분, 예산 상한, 조기 종료 테스트를 추가했습니다.
