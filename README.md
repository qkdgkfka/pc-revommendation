# PC 견적 도우미

```sh
python3 server_fixed.py --port 4000
```

브라우저에서 `http://127.0.0.1:4000`을 엽니다. 기본 서버는 Python 표준 라이브러리로 실행할 수 있습니다.

부품 검색은 다나와·컴퓨존의 공개 상품 목록에서 제품 옵션별 가격, 상세 페이지와 대표 이미지를 가져옵니다. 판매처 선택, 제품명·규격 검색, 필터, 정렬, 다음 페이지를 지원합니다. 목록·선택한 구성·추천 결과의 제품에 마우스를 올리거나 키보드 포커스를 두면 이미지가 표시됩니다.

`data/product_catalog.json`에는 실제 조회한 판매 상품을 저장합니다. 서버는 이를 기본 모델 목록에 추가하며, 새로 조회한 상품은 `data/market_cache.json`에 보관합니다. 가격에는 출처와 확인 시각이 붙고, 24시간이 지나면 이전 가격으로 표시합니다. 조회 실패 시 참고 가격을 현재 판매가로 표시하지 않습니다. 배송비·카드 할인·구매 시점의 변동은 판매처에서 확인합니다.

추천 구성은 성능 기준 모델을 다나와·컴퓨존의 24시간 이내 상품 SKU와 연결할 수 있을 때만 확인가로 사용합니다. 연결된 상품은 상세 URL·대표 이미지·SKU를 함께 보존하고, 연결하지 못한 부품은 화면에 `참고가 · 현재 판매가 미확인`으로 표시합니다. LOW도 숨기지 않지만 판매 SKU가 있으면 이를 먼저 선택합니다.

추천은 선택한 게임·해상도·목표 FPS 또는 작업 용도와 호환성을 우선합니다. RTX 30 시리즈는 자동 추천에서 제외합니다. 예산 내 조합이 없으면 예산을 초과하는 최소 호환 구성을 표시합니다. LOW → MID → HIGH의 가격·성능 역전을 막으며, 별도 업그레이드가 없으면 동일 구성임을 명시해 세 등급을 유지합니다. CPU 소켓·세대·칩셋과 RAM 규격을 검사하고, 출고 BIOS 확인 여부는 별도로 표시합니다.

Steam 하드웨어 설문은 데스크톱 GPU 사용 비율을 보조 점수로 사용합니다. 이는 Steam 설문 참여자의 표본이며 전체 PC 사용자의 전수 조사나 성능 벤치마크는 아닙니다. 추천 요청은 Steam 응답을 기다리지 않고 날짜가 명시된 스냅샷을 읽습니다. 1프레임당 가격은 **본체 부품 합계 ÷ 선택한 게임·해상도의 높음 옵션 예상 평균 FPS**로 계산합니다.

추천 요청끼리 60초 동안 결과를 재사용하고, 한 요청 안에서는 CPU·GPU·RAM별 FPS 계산을 등급 간 공유합니다. 판매처 조회 대기 시간은 단계별로 제한하며, 조회 실패 시 미확인 가격을 구분합니다.

게임 FPS는 GamersNexus·GeekaWhat의 공개 리뷰에서 크롤링한 `data/game_benchmarks.json`을 우선 사용합니다. 현재 13개 게임의 네이티브 실측 48개와 RT/프레임 생성 측정 5개를 포함합니다. 동일 측정 조건의 원문 FPS는 보존하고, 다른 CPU·GPU·해상도·옵션은 보정 추정과 범위를 표시합니다. 실측이 없는 게임은 모델 추정임을 명시합니다. FPS 상한이 있는 게임은 옵션별 FPS가 같을 수 있습니다.

RT·DLSS/FSR·FG 비교를 펼치면 게임과 GPU에서 지원하는 시나리오를 볼 수 있습니다. 측정 자료 기반 값과 대략적인 부하 모델 추정을 구분하며, 생성 프레임 포함 FPS는 실제 렌더 FPS와 분리합니다. 병목 퍼센트는 선택 조건의 자체 모델 추정이며 PC-Builds의 계산식을 복제하거나 해당 사이트의 수치를 가져온 값이 아닙니다.

데이터 갱신:

```sh
python3 scripts/refresh_product_catalog.py --pages 5 --source all
python3 steam_hardware.py
python3 crawl_data.py crawl
python3 -m pip install -r requirements.txt
python3 crawl_game_benchmarks.py
```

`crawl_data.py crawl`은 Tom's Hardware GPU 계층 표를 다시 받아 SQLite의 `average_games` 행을 갱신합니다. `crawl_game_benchmarks.py`는 원문 조건과 FPS 문구를 검증해 게임별 스냅샷을 갱신하며, 원문 구조가 달라지면 기존 데이터를 보존합니다. 출처·원문 조건·수집 시각은 스냅샷과 추천 근거에 남습니다.

회귀 검사:

```sh
python3 -m unittest discover -s tests -v
```

가격과 FPS의 검증 범위는 별개입니다. 정확한 CPU/GPU 성능 기준 모델이 없는 상품은 이웃 모델의 벤치마크를 대신 사용하지 않습니다.
